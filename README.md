# Student Assignment Management System

A Software Engineering academic project focused on system design, project planning, and software cost estimation for a Student Assignment Management System.

## Project Overview

The Student Assignment Management System is a proposed system intended to organize assignment-related activities for students and faculty.

This project focuses on the design and planning aspects of software development rather than the implementation of a working website or application.
